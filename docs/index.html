What the figures establish

Platform-recorded evidence

The source files contain aggregate figures returned by GitHub's API and preserved in public commit history. This page only displays them.

Growing recorded totals

GitHub supplies 14 daily records at a time. Weekly snapshots are merged by UTC date, so overlapping days count once and older recorded days never disappear.

Careful interpretation

Recorded views and full clones grow from the first captured coverage period. Unique-client figures remain 14-day values because GitHub cannot deduplicate a person across weeks. Named release ZIP counts are cumulative.
